# Đọc danh sách nhanh, phân tích theo thứ tự, trạng thái nổi bật, hộp phóng to → v0.4.3

1. Xem trước: duyệt cây thư mục (PDF của thư mục theo tên tự nhiên, rồi từng thư mục con), gửi tên từng thư mục
   ngay khi đọc xong → cột trái hiện dần tức thì; số trang theo cache điền sau. Bấm Phân tích dùng lại danh sách đã duyệt.
   Phiên Phân tích cùng thứ tự cây với danh sách xem trước.
2. Phân tích lần lượt từ hồ sơ đầu danh sách tới cuối: bỏ ưu tiên trang đang hiện trên lưới (gây nhảy thứ tự).
3. Hàng tab: "Đã dừng ở x% (…)" chữ cam đậm nền cam nhạt; "Phân tích xong (…)" chữ xanh lá đậm (cả prototype).
4. Hộp phóng to: S I B (và phím S I B C) chỉ ở tab Hồ sơ; giữa hàng đầu là trạng thái đậm + vị trí
   ("Index (barcode) (10/896)"); trái: tên trang, nhóm nút.
