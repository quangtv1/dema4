# ADR 0009 (D9): Thanh tiêu đề

- **Trạng thái:** Đã chấp nhận, 18/11/2026.
- **Bối cảnh:** Prototype vẽ thanh tiêu đề riêng.
- **Quyết định:** Bản 1.5.0 dùng thanh tiêu đề native của Windows để không gặp lỗi snap layout, kéo cửa sổ
  và DPI. Thanh tiêu đề tự vẽ (SH-09, mức L) để sau nếu thiết kế bắt buộc.
- **Hệ quả:** Tiêu đề cửa sổ đặt là "Sao Mai Ký số — <màn>" (SH-01).
